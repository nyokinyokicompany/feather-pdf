## 主な機能

- **PDFを開く**
  - アプリ内の「PDFを開く」ボタンからシステムファイルピッカー（`ACTION_OPEN_DOCUMENT`）で選択。
  - 他アプリ（ファイルマネージャ、ブラウザのダウンロード、共有など）からの `ACTION_VIEW` / `ACTION_SEND` に対応（`content://` および `file://` 両対応、非シーク可能ストリームの一時キャッシュフォールバック付き）。
- **最近開いたファイル**
  - ホーム画面に最大20件の履歴を表示し、タップで即座に再オープン。
  - 永続URI権限（`takePersistableUriPermission`）を取得して保持。
  - 長押しで履歴から削除可能。権限切れやファイル消失時も安全にエラー表示・履歴削除が可能。
- **快適な閲覧体験**
  - `RecyclerView` による縦スクロール連続表示（ページ間の余白付き）。
  - ページの縦横比を事前取得し、描画前でも正しい高さのプレースホルダーを表示（スクロール跳ねを防止）。
  - **ピンチズーム（1x〜5x）・ダブルタップズーム（1x ⇔ 2.5x）・ズーム中パン/フリング**に対応。ズーム操作中は既存ビットマップをGPUで滑らかに拡大表示し、確定後に表示領域のみを高解像度で再描画。
  - スクロール中に自動表示・静止後に自動消去するページ番号インジケータ（タップでページ指定ジャンプ）。
  - 右端のドラッグ可能な高速スクロールつまみ（ページ数が多いPDFも一瞬で移動）。
  - ページ番号指定ジャンプダイアログ。
  - ファイルごとの最終閲覧ページ・スクロール位置・ズーム倍率・水平パン位置を自動記憶・復元。
  - **夜間モード**（`ColorMatrixColorFilter` による描画時リアルタイム色反転）。
  - タップで半透明ツールバー・システムバーの表示/非表示を切り替え（全画面閲覧）。
  - 画面回転・マルチウィンドウのリサイズにシームレス対応（閲覧位置・ズーム・キャッシュを保持）。
- **安全なエラーハンドリング**
  - パスワード保護PDF、破損PDF、空のPDF、権限切れ・ファイル未検出時にクラッシュせず分かりやすい日本語メッセージを表示。

## 設計・性能上の工夫

1. **極限の軽量構成（APKサイズ極小・高速コールドスタート）**
   - Kotlin + Android標準View（Jetpack Compose / AppCompat / Material Components 不使用）で起動処理とメソッド数を最小化。
   - PDF描画にAndroid標準 `android.graphics.pdf.PdfRenderer` を採用し、ネイティブライブラリを同梱しない。
   - リリースビルドで R8（コード難読化・最適化 + リソース圧縮）を有効化。アイコンはすべてベクタードローアブルで構成。
2. **専用単一バックグラウンドスレッド＋優先度スケジューリング**
   - スレッドセーフでない `PdfRenderer` の全操作を単一の専用描画スレッド（`LightPdf-RenderThread`）へ直列化。
   - 優先度キュー（表示中ページ ＞ ズーム高解像度タイル ＞ 前後1〜2ページ先読み ＞ 大規模PDFのバックグラウンド縦横比スキャン）を採用し、同一優先度内はLIFOで最新の表示要求を最優先処理。画面外になったページの未実行タスクは即座にキャンセル・間引き。
3. **GCスパイクを抑える参照カウント付き `BitmapPool` ＋ `LruCache`**
   - 使用可能ヒープメモリの約1/6を上限とする `LruCache` で1xベースページをキャッシュ。
   - `ARGB_8888` ビットマップを `RefCountedBitmap` で安全にライフサイクル管理し、API 26+ の `Bitmap.reconfigure()` を活用した `BitmapPool` で再利用することで、高速スクロール時のメモリ確保とGC停止を大幅に削減。
4. **OOMを防ぎつつ鮮明なズーム高解像度描画**
   - ズーム中（ピンチ・ダブルタップアニメーション中）は `RecyclerView` のレイアウト再計算を行わず、Canvas行列変換のみで60/120fps描画。
   - ズーム確定後に `PdfRenderer.Page.render()` の `Matrix` 変換を用い、**現在画面に映っている可視領域のみ**を画面ピクセル密度1:1のタイルとして描画。5倍ズーム時でもメモリ消費を画面サイズ相当に抑えつつ、文字をくっきり表示。
5. **ゼロコスト夜間モード**
   - `PdfPageView` の `Paint` に `ColorMatrixColorFilter` を適用するだけで切り替えるため、ビットマップの再描画やキャッシュ破棄が一切発生せず0msで切り替わります。
6. **Liquid Titanium デザインシステム**
   - 深淵なダーク背景（`#070B12`）にチタン光沢（`#B7C6CF` / `#F5FBFF`）とアクセント（`#8A7CFF`）、角丸 `14dp`・8dp基準余白を採用。閲覧画面ではPDFの可読性を最優先し、半透明ツールバーと全画面切替を両立。

## ビルド方法

### 前提環境
- JDK 17
- Android SDK (`compileSdk 35`, `build-tools;35.0.0`, `minSdk 26`)
- Gradle は同梱の Gradle Wrapper（8.9）が自動で取得します

Android Studio で開いてビルドするのが一番簡単です。コマンドラインの場合は、環境変数 `ANDROID_HOME` を設定するか、プロジェクト直下に `local.properties`（`sdk.dir=Android SDKのパス`）を置いてください。

### リリースAPKのビルド

```bash
./gradlew assembleRelease      # macOS / Linux
gradlew.bat assembleRelease    # Windows
```

ビルドが成功すると、デバッグ署名済み（サイドロード可能）のリリースAPKが以下に生成されます。

```text
app/build/outputs/apk/release/app-release.apk
```

Lintチェックを実行する場合:

```bash
./gradlew lint
```
